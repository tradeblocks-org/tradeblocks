# Tradeblocks 3.11.0

## More reusable calculations and replay corrections

The public `@tradeblocks/lib` calculation entrypoint now exposes realized trade performance, stress scenarios, strategy similarity, dated account-equity drawdown and calendar returns, field statistics, and single-tape walk-forward analysis. These are additive exports; existing MCP performance and analysis tools use the shared calculations without changing their input or output contracts. Walk-forward windows outside the available data are now skipped and reported instead of being treated as measured results.

The MCP replay now starts at the trade's entry, avoids opening-rotation and empty quotes, and prices the volatility move at the step's new time during Greeks decomposition. ThetaData backfills preserve source column types. These corrections may change results for affected trades or backfills, but they do not change tool interfaces.

The server and library tests now run before release publication; Docker version and latest tags move only when a new npm package version is published. The security audit also picks up patched MapLibre GL and sharp transitive dependencies. This release follows 3.10.2; the additive library exports warrant a minor version bump.
