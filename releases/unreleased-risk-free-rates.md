# Unreleased — Published risk-free rates

TradeBlocks now publishes the full DTB3 and SOFR FRED histories daily to a separate `rates-data` branch instead of opening weekly code-update PRs. The web app reads the published file by default, caches the last validated copy in IndexedDB, and shows the effective DTB3 date beside Sharpe and Sortino. The Fetch published risk-free rates switch opts out; offline users fall back to the cached file or the bundled rates. Existing CSV import and the library's bundled rate lookups work without an API key or network access.

The MCP server and market-data refresh use the same validated rates with a local disk cache, allowing newer canonical rate slices without rewriting unchanged historical content identities. The release gate checks that the bundled histories are no more than ten calendar days behind the published file; the reviewed `node scripts/rates.mjs seed` command refreshes both tables before a release. This release seed extends the bundles through September 24, 2026 and corrects two previously misdated January 2026 DTB3 observations (which intentionally change January 5 and January 12 slice identities). The CLI's `check --json` reports `current`, `behind`, or `unknown` independently of release gating.
